      Cómo se calcula

      Cada pregunta tiene cuatro respuestas y cada una sale del programa electoral de un partido: PSOE, PP, Vox o Frente Amplio. Cuando eliges una respuesta, ese partido suma un punto.

      El porcentaje de cada partido es su número de puntos dividido entre las preguntas en las que elegiste una propuesta. Las que marcas como «ninguna encaja» no cuentan. Como cada respuesta es de un solo partido, los cuatro porcentajes suman 100 % (puede variar un punto por el redondeo).

      El orden de las respuestas se mezcla al azar en cada partida, y en el conjunto del test cada partido aparece un número de veces parecido en cada posición, para que la posición no dé pistas.

      Las propuestas están resumidas con palabras neutras; la cita literal y la página de cada una están en las fuentes. Es una herramienta orientativa sobre programas, no una encuesta ni una recomendación de voto.
